使い方と注意事項

      
    

    

      
      
基本操作

      
    
        
  1. USBシリアル機器を接続し、「機器を選択」から対象を選びます。
    2. 
        
  2. 必要なら「通信設定」を開き、Baud rate、Data bits、Parity、Stop bits、Flow controlを変更してから「接続」を押します。
    3. 
        
  3. Text / HEX表示を切り替えられます。必要に応じて時刻表示や送信表示をONにします。
    4. 
        
  4. 送信形式をText / HEXから選びます。Textでは改行方式を、HEXでは送るbyte列を指定します。
    5. 
        
  5. 機器制御ではDTR / RTS、BREAK、制御キーを送れます。DTR / RTSは接続しただけでは変更しません。
    6. 
        
  6. 通信内容はセッション中だけメモリに記録され、TXTまたはJSONLとして明示的に保存できます。
    7. 
        
  7. ログを上へスクロールすると追従を自動停止し、新着件数と「最新へ」を表示します。検索や↑/↓のコマンド履歴も利用できます。
    8. 
        
  8. USBが抜けた場合は切断状態へ移り、同じ機器を挿し直したら「再接続」で通信を再開できます。
    9. 
      

      
プライバシー

      
シリアル通信内容はブラウザ内で処理し、このアプリから外部サーバーへ送信しません。通信ログはセッション中のメモリにだけ保持し、保存ボタンを押した場合だけファイルとして端末へ保存します。

      
注意事項

      
    
        
  • Web Serialに対応したブラウザが必要です。非対応の場合は接続操作を無効にして案内します。
    • 
        
  • 専用ターミナルソフトは不要ですが、USBシリアル機器によってはOS側のドライバーが必要です。
    • 
        
  • 接続できない場合は、Arduino IDEや他のシリアルターミナルが同じポートを使用していないか確認してください。
    • 
        
  • ブラウザからCOM番号などの分かりやすいポート名を取得できるとは限りません。
    • 
      

      
DTR / RTSの変更は接続先によってリセットなどを起こす場合があります。BREAKも機器の仕様を確認して使用してください。Clearは画面表示だけを消し、セッションログは残ります。
