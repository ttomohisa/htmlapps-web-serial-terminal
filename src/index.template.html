使い方と注意事項

      
    

    

      
      
基本操作

      
    
        
  1. USBシリアル機器を接続し、「機器を選択」から対象を選びます。
    2. 
        
  2. 115200 / 8-N-1 の設定を確認して「接続」を押します。ページを開いただけでは自動接続しません。
    3. 
        
  3. 受信テキストを確認し、下の入力欄からコマンドを送信します。v0.1.0ではLFを付加します。
    4. 
        
  4. 終了時は「切断」を押します。USBが抜けた場合は状態を解除し、再接続できます。
    5. 
      

      
プライバシー

      
シリアル通信内容はブラウザ内で処理し、このアプリから外部サーバーへ送信しません。v0.1.0では通信ログも永続保存しません。

      
注意事項

      
    
        
  • Web Serialに対応したブラウザが必要です。非対応の場合は接続操作を無効にして案内します。
    • 
        
  • 専用ターミナルソフトは不要ですが、USBシリアル機器によってはOS側のドライバーが必要です。
    • 
        
  • 接続できない場合は、Arduino IDEや他のシリアルターミナルが同じポートを使用していないか確認してください。
    • 
        
  • ブラウザからCOM番号などの分かりやすいポート名を取得できるとは限りません。
    • 
      

      
v0.1.0は通信基盤の最初の版です。Baud rate変更、CR/LF切替、HEX、DTR/RTS、ログ保存などは後続版で追加します。
