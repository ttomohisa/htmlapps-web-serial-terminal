# Web Serial Terminal / シリアル通信ターミナル

USBシリアル機器へブラウザから接続し、受信テキストの確認とコマンド送信を行う Browser Kitty の小さなツールです。

現在の開発バージョン: v0.1.0

[English README](README.md)

## 現在のマイルストーン

v0.1.0 では Serial Foundation を実装します。

- Web Serial 対応可否の判定
- ブラウザの機器選択画面からシリアル機器を選択
- 以前に許可したポートの検出。ただし自動接続はしない
- 115200 / 8-N-1 固定で接続
- UTF-8 テキストをストリーム受信
- テキストコマンド送信。v0.1.0 では LF を自動付加
- 明示的な切断
- 接続、受信、送信、予期しない切断のエラー表示
- 日本語 / 英語UI
- 実行時CDN・外部APIなし

HEX、通信設定変更、タイムスタンプ、Local Echo、DTR / RTS、ログ保存、マクロなどは後続バージョンで追加します。

## 使い方

1. シリアル機器をPCへ接続します。
2. Web Serial対応ブラウザで Web Serial Terminal を開きます。
3. 「機器を選択」を押します。
4. 選択した機器と 115200 / 8-N-1 の設定を確認します。
5. 「接続」を押します。
6. ターミナルで受信テキストを確認します。
7. コマンドを入力し、Enter または「送信」を押します。v0.1.0 では LF が付きます。
8. 終了時に「切断」を押します。

ページを開いただけで機器へ自動接続することはありません。

## プライバシー

シリアル通信のRX/TXデータはブラウザ内で扱い、Browser Kittyのサーバーへ送信しません。

単一HTML版では Content Security Policy により実行時のネットワーク接続を遮断します。Analytics、Telemetry、外部フォント、実行時CDNも使用しません。

v0.1.0ではターミナル通信内容を永続保存しません。端末内に保存する可能性があるのは言語設定のみです。

## ブラウザ対応

起動時に Web Serial の対応可否を判定します。非対応ブラウザでは接続を試みず、理由を案内します。

初期実装の主対象はデスクトップ版Chromium系ブラウザです。FirefoxデスクトップやAndroidは、正式な対応表記を行う前に実際のリリース成果物と実機で確認します。Web Serialを利用できないSafari環境は非対応です。

## v0.1.0の制限

- 通信設定は 115200 baud / 8 data bits / parity none / 1 stop bit / flow control none 固定です。
- 送信時にLFを付加します。
- Textモードのみです。
- ログ保存はまだありません。
- DTR / RTS / BREAK はまだありません。
- ANSI / VT100 エミュレーションは行いません。
- ブラウザからCOM番号などの分かりやすいポート名を取得できるとは限りません。

v0.1.0の受け入れ条件とv0.2.0〜v1.0.0の計画は APP_SPEC.md に記載しています。

## ビルド

Windowsでは次を実行します。

    build-standalone.bat

リポジトリチェックではPowerShell事前検証、通常版とSelf-extract版の単一HTML生成、CSP・埋め込みルールの検証、リポジトリ直下HTMLの生成まで行います。

生成されたHTMLを直接編集せず、src/index.template.html を変更して再ビルドします。
